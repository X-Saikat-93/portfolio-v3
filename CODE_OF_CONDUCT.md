# Code of Conduct

The portfolio should be a calm, constructive project to work on. Anyone
participating in issues, pull requests, reviews, discussions, or other project
spaces is expected to:

- communicate respectfully and assume good intent;
- critique code, design, and decisions rather than people;
- provide concrete context when reporting a problem;
- protect private owner information and unpublished portfolio material;
- accept corrections and maintain a professional standard in disagreement.

Unacceptable behavior includes harassment, discrimination, threats, doxxing,
publication of private information, deliberate disruption, credential or
secret disclosure, and knowingly submitting fabricated portfolio content.

## Enforcement

The repository maintainer may remove comments, close contributions, restrict
participation, or take other action needed to protect the project and its
participants. For sensitive conduct concerns, contact the maintainer privately
through GitHub rather than opening a public issue. Reports should include the
relevant link, dates, context, and any requested confidentiality.

This code applies wherever project participation represents the repository or
its maintainer.
